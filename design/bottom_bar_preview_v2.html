Gringotts · M2 前置修正 · 底栏与「记一笔」重设计 v2

三 tab 的艺术感 × 3  ·  「记一笔」的位置 × 3

v2 按你的三条意见重做：① 底栏**只放三个 tab**（不塞按钮）② 三个 tab 本身要**更有艺术感**（不是通用「图标+汉字」）③ 「记一笔」的**位置与按钮本体**推倒重来（前三个位置作废：底栏上方通栏 / 卡片内 / 底栏居中）。可自由组合，例如「T1 + P2 + D2」。
两条铁律没变：①「记一笔」只在**分析页**存在（资产/统计页彻底没有它）② 底栏总高恒定、切换不跳动。另外三 tab 我保留了你认可的「图标 + 汉字」结构，只在线稿、字距、选中态三处做文章 —— 不用渐变、不用发光、不加投影。

III

按钮本体：三种做法（可单独换）

按钮形状与位置可以拆开选：位置挑 II 里的，样式挑这里的。全部无投影、无渐变、无发光。

D1 · 压印金块
＋ 记一笔

纯色香槟金实心，内侧 1px 深金描边模拟「压印边」—— 不用投影也有金属重量感。文字 sans 15·w600。

D2 · 金环
＋ 记一笔

1.25px 金环 + 金字，按下时内部渐入极淡金底（120ms 一次性）。与快记页确认键、导出键同一套语言。

D3 · 双线薄片
＋ 记一笔

外 1px 金线 + 内 1px 极淡金线（间距 3），像钱币边缘。最「精工」，也最挑像素对齐（1px 线在非整数缩放下会糊）。

怎么回我：三处各挑一个即可，例如 T1 / P1 / D1（我的推荐组合），或 T3 + P2 + D2。
推荐理由（一句话）：T1 细线滑动 保留你现在认可的结构、只提升质感；P1 右下金键 让「3 秒一笔」是拇指原位就能完成、且不占底栏；D1 压印金块 去掉渐变但仍保留金色的重量感。
若还想改：告诉我具体不爽点（「线太细」「金太亮」「字要更大」「不要线稿图标」），我出 v3。你拍板前不派工。
